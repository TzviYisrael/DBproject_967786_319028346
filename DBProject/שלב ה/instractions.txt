Stage E - BetMaster Admin GUI

Run instructions
================

1. Start PostgreSQL from the repository root:

   docker compose up -d

2. On a fresh machine or empty Docker volume, load the Stage D backup:

   docker exec -i betmaster_db psql -U betmaster_user -d betmaster < .\שלב_ד\backup4.sql

   If the Docker volume already contains the project database, skip this step.

3. Install the Python dependencies:

   cd .\שלב_ה
   python -m pip install -r requirements.txt

4. Run the graphical application:

   python main.py

Database connection
===================

Host: localhost
Port: 5432
Database: betmaster
User: betmaster_user
Password: betmaster_pass

What the application contains
=============================

- Home screen with navigation to all system screens.
- Data Management screen with CRUD for all 40 public database tables.
- Foreign keys are displayed as readable names, such as user names, team names,
  match descriptions and stadium names.
- Update flow follows the project requirement: the user enters the primary key,
  clicks Fetch, edits the loaded fields and saves the update.
- Actions screen for Stage B queries and Stage D procedures/functions.

Available Stage B queries

- Suspicious Winning Patterns

- Monthly Cash Flow
